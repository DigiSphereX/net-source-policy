# Contributing

Thanks for your interest in this project!

- **Bug reports**: open an issue, describe the problem, your OS (Windows 10/11) and the
  steps that reproduce it. Screenshots or logs help a lot.
- **Feature requests**: open an issue and explain the use case.
- **Pull requests**: fork the repository, make a focused change, and open a PR against
  `main`. Keep changes small, test them if you can, and read the README first so your
  change fits the existing behavior.

Questions are welcome in issues so the whole community can see the answers.
